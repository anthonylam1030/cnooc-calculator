# PetroChina 0857 Investment Report

Interactive PetroChina (0857.HK) investment-analysis site with an 18-quarter integrated-oil model, Brent sensitivity, segment profit analysis, natural-gas profit history, and server-side live quote proxy.

## Run

```bash
npm start
```

Then open `http://localhost:3000`.

## Features

- 0857.HK share price, Brent and CNY/HKD quote proxy via `/api/quotes`
- 2022Q1–2026Q2 historical adjusted earnings
- Upstream, refining & chemicals, marketing and natural gas segment analysis
- Brent US$60–120 sensitivity
- Per-share EPS and dividend outputs
- Natural gas operating-profit history and seasonality

Historical/model values are research inputs and estimates unless explicitly sourced as company-reported actuals.
